#
#   shared <variable>       module variable written in the tree that is neither
#                           indexed by the current hru/object nor threadprivate
#   saved  <routine>:<var>  local that keeps its value between calls on purpose
#   io     <routine>        routine that reads or writes files
#
# Each line ends with the reason the entry is safe.
